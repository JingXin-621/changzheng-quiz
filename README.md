# 🚩 长征红色问答挑战

## 项目简介

一款以"传承红色基因，学习长征精神"为主题的互动问答 Web 应用。每天 5 道精选长征历史知识题，通过答题闯关积累积分、提升军衔、解锁成就，并可与好友比拼排行榜。

电脑和手机浏览器均可直接打开使用。

---

## ✨ 核心功能

| 功能 | 说明 |
|------|------|
| ✏️ **每日答题** | 每天 5 道随机长征知识题，计时作答，答完即时解析 |
| ⭐ **军衔进阶** | 从"新兵"到"司令员"共 17 个军衔等级，积分驱动升级 |
| 🏅 **成就系统** | 12 种成就徽章：答题新星、闪电答题、全对通关等 |
| 🏆 **排行榜** | 总榜/周榜/日榜，模拟竞争，激励持续参与 |
| 📖 **知识库** | 50+ 道题目永久可查，每题带详细历史解析 |
| 📤 **分享海报** | 生成红金主题战绩海报，支持保存图片和社交分享 |
| 🔥 **连续打卡** | 每日坚持答题，累计连续天数 |
| 📱 **响应式** | 手机端底部导航、电脑端侧栏导航，自适应布局 |

---

## 🚀 使用方式

### 方式一：电脑双击打开

直接双击 `index.html`，浏览器中即可使用。

### 方式二：手机 + 电脑同时访问（需同一 Wi-Fi）

```bash
# 在项目目录下运行
python server.py
```

终端会显示两个地址：
- `http://localhost:8000` → 电脑浏览器打开
- `http://192.168.x.x:8000` → 手机浏览器输入此地址

### 方式三：部署到任意 Web 服务器

将 `index.html` 放在任意静态文件服务器目录下即可。

## 🎮 玩法说明

### 答题规则
- 每天 5 道题，每题限时 **30 秒**
- 答对一题基础 +100 分
- **速度奖励**：10 秒内答对 +20 分，5 秒内 +30 分
- **连对奖励**：连续答对每多一题 +10 分
- **全对奖励**：5 题全对额外 +50 分

### 军衔进阶（17 级）

| 🎖️ 上等兵 | 300 | 🥇 上校 | 8,200 |
| 🛡️ 下士 | 600 | 👑 大校 | 10,000 |

### 成就徽章
- ✏️ 初露锋芒 — 首次答题
- 💯 全对通关 — 一次答题 5 题全对
- ⚡ 闪电答题 — 5 秒内答对一题

## 📊 题库覆盖范围

50 道精选题目涵盖：

- 🕐 时间节点（出发、到达、会师时间）
- ⚔️ 经典战役（湘江、四渡赤水、飞夺泸定桥、腊子口等）
- 🏛️ 重要会议（遵义会议等）
- 👤 英雄人物（陈树湘、彭德怀、贺龙等）
- 💕 感人故事（半条被子、金色鱼钩、一袋干粮等）
- 📝 诗词文化（毛泽东长征诗词）
- 🌍 行军路程（雪山、草地、大江大河）
- 📊 基本数据（人数、里程、时间）
- 🔥 精神传承（长征精神内涵与意义）
